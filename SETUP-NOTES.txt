ZYFER UPDATED SOURCE — CHECKED SETUP NOTES

GitHub repository Secrets:
- GROQ_KEY: existing Groq API key
- ELEVENLABS_API_KEY: ElevenLabs API key

GitHub repository Variable (not a Secret in this workflow):
- ELEVENLABS_VOICE_ID: your custom female voice ID from ElevenLabs

Setup:
- Put build.yml at .github/workflows/build.yml
- Put main.dart and pubspec.yaml in the repository root.
- Keep the assets folder in the repository root if you have app assets/logo.png.
- This workflow reads the voice ID from vars.ELEVENLABS_VOICE_ID.
  If it is missing/empty, code falls back to the sample George voice.
- Groq model is now openai/gpt-oss-120b because llama-3.3-70b-versatile
  was shut down for developer/free tiers on 16 Aug 2026. Check Groq console
  for model access, usage limits and any applicable billing.

Included:
- Groq conversational AI with short-term in-memory chat context.
- English, Hinglish and Hindi response modes.
- Sir by default; Friend mode only when explicitly requested; Sir mode can be restored.
- Custom ElevenLabs voice first, Android TTS fallback if ElevenLabs fails.
- App opening, alarms, timers, Google search and YouTube search.
- Voice command to pause listening; tap the microphone to resume.

Known limitations:
- Background listening/foreground service is NOT included; app must remain foreground for continuous listening.
- Live web search is NOT wired into the app; AI answers rely on model knowledge.
- Conversation history is in memory and is lost when the app process restarts.
- API quota, internet, provider uptime and account permissions cannot be guaranteed.
- --dart-define embeds API keys in the APK. GitHub Secrets protect repository settings,
  but compiled keys can be extracted from a distributed APK. Personal testing only;
  production should use a private backend proxy.
- Files were statically inspected, but no Flutter/Android build or device test was run here.
  Verify the GitHub Actions build before installing.
